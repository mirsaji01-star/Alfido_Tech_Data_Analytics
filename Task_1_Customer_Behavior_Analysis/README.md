Task 1 - Customer Behavior Analysis Report and Notebook
## Overview
Analyzed customer purchasing patterns, product preferences, payment methods, and customer segments using Python.

## Tools Used
- Python, Pandas, NumPy
- Matplotlib, Seaborn
- Google Colab, RFM Analysis

## Key Findings
- 250,000 purchase records and 49,673 unique customers.
- Books generated the highest sales (approximately ₹204.9 million).
- Credit cards were the most-used payment method (41%).
- Repeat purchase rate: 96.61%.

## Recommendations
1. Reward loyal customers with special offers.
2. Promote popular product categories.
3. Use targeted campaigns to retain at-risk customers.
