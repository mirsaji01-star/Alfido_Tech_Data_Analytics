Task 2: Sales Performance Analysis
## Overview

Analyzed Superstore sales data to understand sales performance, profitability, customer segments, and monthly sales trends using Python.

## Tools Used

- Python, Pandas, NumPy
- Matplotlib, Seaborn
- Google Colab

## Key Findings

- Total sales: $2,297,201.
- Total profit: $286,397.
- Total orders: 5,009.
- Total customers: 793.
- Technology was the highest-performing category in the reported analysis.

## Recommendations

1. Promote high-performing product categories.
2. Develop targeted marketing strategies for customer segments.
3. Monitor discounts to improve profitability.
